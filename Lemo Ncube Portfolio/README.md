## 🧠 Featured Projects

### 1. Bias Audit Report
- **Description**: Fairness audit using the UCI Adult dataset to identify and mitigate gender bias.
- **Tools**: Python, Logistic Regression, IBM AIF360, Matplotlib
- **Outcome**: Applied reweighing to reduce disparate impact and improve fairness metrics.

### 2. Sentiment Analysis Dashboard
- **Description**: An interactive dashboard that analyzes public reviews and classifies sentiment.
- **Tools**: Hugging Face Transformers, Pandas, Plotly, Streamlit
- **Features**: Confidence scores, keyword extraction, batch processing, and sentiment visualizations.

### 3. AI Study Buddy – “Miss TT” (Capstone Project)
- **Description**: A lightweight, voice-enabled AI chatbot that answers academic questions.
- **Tools**: Cohere (LLM), Whisper (Speech-to-Text), Flask
- **Features**: Voice input, real-time text responses, accessible web-based interface.
